# HU-003: Llamado de Asistencia

## Historia de Usuario
Como instructor, quiero registrar la asistencia de los aprendices a las sesiones de formación, para controlar la asistencia y cumplimiento.

## Criterios de Aceptación
- El instructor puede crear un llamado de asistencia con fecha y hora.
- El instructor puede marcar la asistencia de cada aprendiz (Presente/Ausente/Justificado).
- El sistema muestra el historial de asistencia por aprendiz.
- El instructor puede editar la asistencia registrada.
