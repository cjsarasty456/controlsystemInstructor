## Historia de Usuario
Como instructor, quiero cargar y consultar el reglamento del aprendiz, para tener disponible la normativa como referencia.

## Criterios de Aceptación

- El instructor puede visualizar el reglamento cargado.
- El instructor puede descargar el reglamento.
- El sistema muestra la fecha de última actualización del reglamento.
