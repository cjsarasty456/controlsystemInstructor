# HU-001: Registro de Trabajos

## Historia de Usuario
Como instructor, quiero registrar los trabajos asignados a los aprendices, para llevar un control de las actividades realizadas.

## Criterios de Aceptación
- El instructor puede crear un nuevo registro de trabajo con título, descripción, fecha y aprendiz asignado.
- El instructor puede editar la información de un trabajo existente.
- El instructor puede eliminar un trabajo registrado.
- El sistema muestra la lista de trabajos registrados.
