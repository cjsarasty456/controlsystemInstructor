# HU-002: Gestión de Evidencias

## Historia de Usuario
Como instructor, quiero subir y gestionar evidencias de aprendizaje, para documentar el progreso de los aprendices.

## Criterios de Aceptación
- El instructor puede subir archivos (fotos, documentos, PDF).
- El instructor puede asociar una evidencia a un trabajo específico.
- El instructor puede visualizar las evidencias registradas.
- El instructor puede eliminar una evidencia.

- Trabajo asociado: "Proyecto Base de Datos"
