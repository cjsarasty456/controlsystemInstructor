# HU-004: Control Académico SENA

## Historia de Usuario
Como instructor, quiero registrar el control académico conforme a los lineamientos del SENA, para cumplir con los requisitos institucionales.

## Criterios de Aceptación
- El instructor puede registrar competencias y resultados de aprendizaje.
- El instructor puede vincular trabajos y evidencias a competencias.
- El sistema genera reportes de avance por competencia.
- El instructor puede visualizar el porcentaje de avance por_Resultado de Aprendizaje (RA).

## Datos de Prueba
- Competencia: "Diseñar base de datos relacionales"
- Resultado de Aprendizaje: "RA1: Identifica requerimientos"
- Avance: 75%
